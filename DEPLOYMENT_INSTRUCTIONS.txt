🚀 PASO 2: DEPLOYMENT A RAILWAY (RECOMENDADO)

Opción A - Desde GitHub:
   1. Ir a: https://railway.app
   2. Click "New Project"
   3. Seleccionar "Deploy from GitHub repo"
   4. Elegir: carlicode/cv-analyzer-kiro
   5. Branch: 4-professional-frontend
   6. Railway detectará automáticamente Python
   7. Agregar variables de entorno:
      • OPENAI_API_KEY=tu_key
      • AWS_BEDROCK_REGION=us-east-1
   8. Deploy automático

Opción B - Desde CLI:
   $ npm install -g @railway/cli
   $ railway login
   $ railway init
   $ railway up

Resultado:
   → Railway te dará una URL: https://tu-app.railway.app
   → Frontend: https://tu-app.railway.app/
   → API: https://tu-app.railway.app/analyze

🌐 PASO 3: DEPLOYMENT A AWS (ALTERNATIVO)

Backend (Lambda):
   $ sam build
   $ sam deploy --guided

Frontend (S3 + CloudFront):
   $ aws s3 mb s3://talentscope-ai-frontend
   $ aws s3 sync frontend/ s3://talentscope-ai-frontend/
   $ aws s3 website s3://talentscope-ai-frontend/ \
       --index-document index.html

Actualizar API endpoint en frontend/app.js:
   const API_ENDPOINT = 'https://tu-api-gateway.amazonaws.com/analyze';
