     Comando: make deploy-railway

🚀 QUICK START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  AWS Lambda:
  ──────────
  1. brew install aws-sam-cli
  2. aws configure
  3. sam build --use-container
  4. sam deploy --guided

  Railway:
  ────────
  1. npm install -g @railway/cli
  2. railway login
  3. railway init
  4. railway up
  5. railway variables set AWS_REGION=us-east-1
  6. railway variables set AWS_ACCESS_KEY_ID=tu_key
  7. railway variables set AWS_SECRET_ACCESS_KEY=tu_secret
