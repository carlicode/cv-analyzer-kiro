🔍 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Error: "Docker not running"
  ───────────────────────────
  Solución: Inicia Docker Desktop
  
  open -a Docker
  # Espera 30 segundos
  docker ps

  Error: "Model access denied"
  ────────────────────────────
  Solución: Habilita Claude Sonnet 4.6 en Bedrock
  
  1. https://console.aws.amazon.com/bedrock/
  2. Model access → Manage model access
  3. Busca "Claude Sonnet 4.6"
  4. Marca checkbox → Save changes
  5. Espera 2-3 minutos

  Error: "Stack already exists"
  ─────────────────────────────
  Solución: Actualiza el stack existente
  
  sam deploy  # Sin --guided
